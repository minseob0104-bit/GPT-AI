# GPT-AI
To become a stock expert with GPT
## Introduction
This project is an advanced quantitative trading and backtesting engine designed to automate market analysis and generate high-probability entry/exit signals based on systematic algorithmic models.

## Key Features
- **Multi-Indicator Signal Engine**: Real-time tracking of advanced technical indicators (e.g., MACD, RSI, WaveTrend) to detect momentum shifts and trend reversals.
- **Backtesting & Compounding Simulator**: Validates trading strategies against historical data with precise capital reinvestment ratios (e.g., 1/2 or 1/3 scaling) to maximize portfolio growth.
- **Automated Risk Management**: Built-in maximum drawdown (MDD) protection, dynamic stop-loss, and fractional position sizing to safeguard trading capital.

## Usage
1. **Installation / Download**: Clone the repository and install the required dependencies using `pip install -r requirements.txt`.
2. **Execution / Run**: Configure your API credentials in `config.json` and execute `python main.py` with the `--mode backtest` or `--mode live` argument.
